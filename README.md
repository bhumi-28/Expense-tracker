# Expense-tracker

A simple expense tracker built using the MERN stack — **MongoDB, Express, React, and Node.js**.

---

## Features
- Add and delete transactions  
- Track income and expenses  
- View balance and history  
- Simple, responsive UI  

---

## Tech Stack
- Frontend: React  
- Backend: Node.js, Express  
- Database: MongoDB
